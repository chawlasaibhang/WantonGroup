# wantongroup.com

Static website for Wanton Group (Mumbai, since 1969).

- `dist/`: upload-ready site
- `src/`: source pages, partials and assets
- `python3 build.py`: rebuild `dist/` (needs Pillow)
- `_original/`: the previous live site, for rollback

See [HANDOVER.md](HANDOVER.md) for what changed, how to upload and how to edit.
